# Тестирование сервиса Mesto
## О проекте
В рамках учебного проекта было проведено ручное тестирование веб-сервиса Mesto. Работа состояла из двух этапов:
1. Регрессионное тестирование сервиса по готовым тест-кейсам.
2. Ретест ранее найденных дефектов для проверки их исправления разработчиками.

В ходе проекта были изучены тестовые сценарии, проверена работа приложения на тестовом стенде, зафиксированы результаты проверок и оформлены баг-репорты.
