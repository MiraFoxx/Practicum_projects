# Тестирование API Яндекс Прилавка
Учебный проект в рамках курса «Инженер по тестированию» в Яндекс Практикуме.
В рамках проекта тестировалась новая функциональность API сервиса Яндекс Прилавок.
### Выполненная работа
* Анализ требований и документации API в Apidoc.
* Составление чек-листа для новой функциональности.
* Тестирование API с помощью Postman.
* Проверка API-запросов для работы с корзиной, наборами продуктов и расчета доставки.
* Проверка расчета стоимости доставки.
* Поиск и оформление баг-репортов.
* Подготовка отчёта о результатах тестирования.
