# Тестирование новой версии Яндекс Маршрутов
## О проекте
Учебный проект в рамках курса «Инженер по тестированию» в Яндекс Практикуме.
В новой версии сервиса появилась возможность заказать каршеринг.
### Выполненная работа
- Составление чек-листа на вёрстку формы бронирования и элементов навигационной карты.
- Составление чек-листа на логику работы окон «Способ оплаты» и «Добавление карты».
- Составление тест-кейсов для кнопки «Забронировать».
- Проведение тестирования приложения по подготовленной тестовой документации.
- Поиск и оформление баг-репортов.
