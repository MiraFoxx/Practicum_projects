# Тестирование сервиса Яндекс Маршруты
## О проекте
Учебный проект в рамках курса "Инженер по тестированию" в Яндекс Практикуме.
Провела тестирование валидации полей ввода, а также логики расчета стоимости и времени поездки на автомобиле.
Составляла тестовые сценарии, проверяла граничные и некорректные значения, находила и фиксировала дефекты.
