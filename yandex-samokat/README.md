# Дипломный проект — тестирование Яндекс Самокат

Комплексное тестирование сервиса Яндекс Самокат, включающее проверку веб-приложения, мобильного приложения и API.

## О проекте
- Составлен чек-лист для проверки веб-приложения и проведено функциональное тестирование.
- Подготовлены тест-кейсы для мобильного приложения и выполнено тестирование функциональности.
- Составлен чек-лист для тестирования API по требованиям и документации.
- Проведено тестирование и оформлены баг-репорты по обнаруженным дефектам.

## Виды тестирования

- Функциональное тестирование
- Регрессионное тестирование
- Тестирование мобильного приложения
- API-тестирование
- Валидация полей
- Тестирование по требованиям и макетам
