# Тестирование Яндекс Метро
## О проекте
Учебный проект в рамках курса «Инженер по тестированию» в Яндекс Практикуме.
В рамках проекта тестировалась новая версия мобильного приложения Яндекс Метро после рефакторинга.
### Выполненная работа
* Анализ требований и подготовка чек-листов для функционального тестирования.
* Составление чек-листа для регрессионного тестирования.
* Проверка работы приложения на Android.
* Тестирование мобильных функций: работа с сетью, геолокацией, ориентацией экрана, уведомлениями и энергосбережением.
* Поиск и оформление баг-репортов.
* Подготовка отчёта о результатах тестирования
